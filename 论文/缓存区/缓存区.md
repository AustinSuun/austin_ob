## 🔹 3D 点云目标检测（anchor-free + Transformer/混合）

这里 anchor-free 主要依赖 **中心点 / voxel 中心 / query-based** 预测，与 Transformer 结合后效果很好：

1. **PointFormer (NeurIPS 2021)**
    
    - 结合 PointNet++ 层级特征提取 + Transformer，全局上下文建模强，属于 anchor-free 思路。
        
2. **Group-Free 3D (ICCV 2021)**
    
    - 在 3D 检测里非常有代表性，完全抛弃 anchor/proposal，直接用 Transformer 做中心点预测和 box 回归。
        
    - 是 anchor-free + Transformer 的里程碑方法。
        
3. **3DETR (ICCV 2021)**
    
    - 把 DETR 思路扩展到点云，直接基于 set prediction，anchor-free。
        
    - 适合研究 anchor-free + Transformer 在 3D 的纯粹表现。
        
4. **PV-RAFT, Voxel Transformer 系列 (2021–2022)**
    
    - 虽然很多 voxel-based 方法传统上用 anchor，但部分工作改为 anchor-free 的中心点预测，并用 Transformer 融合局部 voxel 特征和全局上下文。
        
5. **TransFusion (CVPR 2022)**
    
    - 多模态 LiDAR+Camera 融合，用 Transformer 融合 BEV 特征，anchor-free head，效果在 KITTI/nuScenes 都很强。
        

---

## 📌 总结

- **2D anchor-free + Transformer** 的代表：  
    **DETR → Deformable DETR → DAB-DETR / DN-DETR 等改进**。
    
- **3D anchor-free + Transformer** 的代表：  
    **Group-Free 3D、3DETR、TransFusion**。
    

这些方法都摆脱了 anchor 的手工设计，Transformer 提供了全局关系建模与跨模态融合能力，是当前 anchor-free 检测最突出的方向。
