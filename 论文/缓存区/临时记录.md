有的 — 在 2024–2025 年间有一串把 **Mamba / State-Space Models (SSM)** 引入 3D 点云、BEV 以及多模态融合的论文。下面把主要、最相关的工作按类别列清楚（带一句话概述 + 参考），方便你跟进阅读或拿去做比较/复现。

# 主要点云 / 3D 检测方向（Mamba / SSM）

- **Mamba3D — _Mamba3D: Enhancing Local Features for 3D Point Cloud Analysis via State Space Model_ (2024)**  
    专门把 Mamba/SSM 结构改造为点云 backbone，提出 Local Norm Pooling、双向 SSM 等以提升局部几何特征与全局建模。论文与代码都有公开。 ([arXiv](https://arxiv.org/abs/2404.14966?utm_source=chatgpt.com "Mamba3D: Enhancing Local Features for 3D Point Cloud Analysis via State Space Model"))
    
- **Voxel Mamba — _Voxel Mamba: Group-Free State Space Models for Point Cloud based 3D Object Detection_ (2024)**  
    把体素空间序列化为单条序列并用 SSM（Mamba）做 group-free 处理，兼顾空间邻近性与线性复杂度，针对 Waymo / nuScenes 做了检测实证。 ([arXiv](https://arxiv.org/abs/2406.10700?utm_source=chatgpt.com "Voxel Mamba: Group-Free State Space Models for Point Cloud based 3D Object Detection"))
    
- **3DET-Mamba — _State-Space Model for End-to-End 3D ..._ (NeurIPS 2024)**  
    NeurIPS 会议/论文中有将 SSM 应用于端到端 3D 检测的工作（展示了在检测任务上的效果提升与训练策略）。 ([NeurIPS Proceedings](https://proceedings.neurips.cc/paper_files/paper/2024/file/547108084f0c2af39b956f8eadb75d1b-Paper-Conference.pdf?utm_source=chatgpt.com "3DET-Mamba: State Space Model for End-to-End 3D ..."))
    
- **StruMamba3D / UniMamba / 相关变体（2025）**  
    后续工作如 StruMamba3D、UniMamba 等在自监督、统一时空/通道表示或把卷积与 SSM 结合方面做了延伸（更多结构化/多尺度的 SSM 变体）。 ([arXiv](https://arxiv.org/html/2506.21541v1?utm_source=chatgpt.com "StruMamba3D: Exploring Structural Mamba for Self- ..."))

# BEV / 多模态融合方向（LiDAR ↔ Camera）

- **MambaBEV / BEVMamba（2024–2025）**  
    把 Mamba 用在 BEV 表示与时间融合中（提出 TemporalMamba 等模块来做长期序列建模与 BEV 特征重排），专注自动驾驶场景的时序 BEV 融合。 ([arXiv](https://arxiv.org/html/2410.12673v2?utm_source=chatgpt.com "MambaBEV: An efficient 3D detection model with Mamba2"))
    
- **Dual-Domain Homogeneous Fusion with Cross-Modal Mamba (Mar 2025)**  
    直接将 “跨模态 Mamba” 用作融合器，提出双域同质融合策略以改善 LiDAR–Camera 融合的对齐与信息传递。该文把 Mamba 当作跨模态交换/聚合的核心模块。 ([arXiv](https://arxiv.org/html/2503.08992v2?utm_source=chatgpt.com "Dual-Domain Homogeneous Fusion with Cross-Modal ..."))
    
- **后续/相关（2025+）**  
    还有 2025 年以后出现的多模态方法（如把 Mamba 用于 BEV 融合但保留高度信息、或结合几何增强表示的工作），显示该方向在快速扩展。 ([arXiv](https://arxiv.org/html/2507.04369v1?utm_source=chatgpt.com "Height-Fidelity Dense Global Fusion for Multi-modal 3D ..."))

## 🔎 分类解析

### 1. **纯 Transformer**

- **Point Transformer V3 (2023)**：点云领域经典升级版，attention 改进。
    
- **VoxFormer (2023)**：体素级 Transformer，更适合稀疏 3D 表征。
    
- **UniTR (2024)**：统一 Transformer，天然 anchor-free，支持多模态。
    

### 2. **Mamba / SSM**

- **Voxel-Mamba (2024)**：效率优于 self-attention，更适合大规模点云。
    
- **BEV-Mamba (2024)**：将 BEV 表征与 SSM 结合，解决长序列时间建模。
    
- **Sparse Mamba3D (2025)**：专注稀疏点云场景，减少显存消耗。
    X

### 3. **Transformer + CNN 融合**

- **PETR v2 / StreamPETR (2023)**：仍保留部分卷积 backbone，但 Transformer 主导。
    
- **Occ-BEVFormer (2024)**：融合 occupancy grid 与 BEV 表征。
    

### 4. **时序建模**

- **StreamPETR (2023)**：显式处理连续帧输入。
    
- **BEV-Mamba (2024)**：利用 SSM 的时序建模特性，优于时序 Transformer。
    

### 5. **多模态**

- **UniTR (2024)**：LiDAR + Camera + Radar 融合。
    
- **Gaia3D (2025)**：多模态预训练大模型，趋势走向。

## 📊 Benchmark

- **nuScenes**：目前主流，评估 3D detection, tracking, map prediction。
    
- **Waymo Open Dataset**：车规级点云检测，体量大，测试计算代价高。
    
- **KITTI**：经典但逐渐退出 SOTA 对比。
    
- **ONCE / Argoverse 2**：强调大规模自动驾驶场景。
    
- **Occ3D (2024)**：新提出的 occupancy-based benchmark，检测+语义分割一体化。
    

---

## 🚀 未来趋势总结

1. **Transformer → Mamba 过渡**：Mamba 类模型在长序列点云和 BEV 时序任务表现更优，可能成为新 backbone。
    
2. **多模态大模型化**：从单 LiDAR 转向 LiDAR+Camera+Radar 的融合，甚至大模型预训练（Gaia3D）。
    
3. **时序一致性建模**：不仅是 detection，还要 tracking & motion forecasting 一体化。
    
4. **Occupancy 表征兴起**：取代纯 BEV，更细粒度建模 3D 场景。
    
5. **Benchmark 更新**：KITTI 已不够挑战性，未来更关注 Waymo、nuScenes、ONCE、Occ3D。

## 📌 观察与总结

1. **Anchor-Free 已成为主流**
    
    - 2023–2025 的 SOTA 几乎清一色 **Anchor-Free**（预测中心点/关键点 + 回归尺寸/方向）。
        
    - Anchor-Based (如 PV-RCNN, CenterPoint 早期 anchor-based 变体) 已经逐渐退出舞台。
        
2. **架构演化趋势**
    
    - **2023 前**：Voxel/Pillar CNN 占主导（PointPillars, SECOND, CenterPoint）。
        
    - **2023–2025**：**Transformer 主导**，结合 Sparse voxel, Group attention, Window attention 等。
        
    - **Pillar-based**（如 PillarNeXt）被证明依旧有生命力（轻量 & 实时）。
        
3. **多模态趋势**
    
    - LiDAR-only 模型在 Waymo / nuScenes 仍竞争激烈，但越来越多工作探索 **Camera+LiDAR 融合**。
        
4. **应用方向**
    
    - **Waymo / nuScenes**：主流 benchmark，几乎所有新 SOTA 在这里报告。
        
    - **KITTI**：逐渐淡出，作为小规模验证。
