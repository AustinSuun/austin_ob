为什么数量少的小物体也能 增强特征？

解析 GS-Mamba 如何通过“信噪比提升”而非“增加数量”来拯救稀疏识别。

1. 从“大海捞针”到“精确定位”

即使小物体的 Token 占比只有 1%，在不同的计算模式下，它的 **“特征显示度”** 是完全不同的：

传统方案 (固定 128 长度) 信号被极度稀释 (1/128)

Mamba 的隐藏状态 $h$ 在经过 95% 的空白位时，会产生严重的特征衰减或背景偏移。

DAPC 打包方案 (打包至 32) 信号浓度提升 (1/4)

在同一个 SSD 矩阵计算块中，小物体的权重占比提升了数倍，模型更容易捕获其几何梯度。

特征质量的“代差”

小物体的 Token 少，所以每一个 Token 必须承载更多的信息。

● 传统体素： 只是一个“点”。
● 高斯 Token： 虽然也是一个 Token，但它通过协方差 Σ 显式带入了 **方向感**（它是立着的还是横着的？）。

单 Token 信息量对比 (几何熵)

2. 隐藏状态的“激活一致性”

Mamba 是循环处理的。在传统变长填充下，模型扫描过长 Padding 就像在**走神**。

通过 DAPC 压缩序列长度并配合高斯 Token 的高保真度，Mamba 的隐藏状态在小物体的关键特征点上能够保持更强的 **峰值响应**，而不会被前后的 Padding 背景“软化”。

总结：不是靠“人多”，是靠“人精”

“虽然小物体的 Token 依然很少，但通过 DAPC 我们让它们在计算块内的 **相对密度** 提升了；通过高斯化我们让单个 Token 的 **几何描述力** 增强了。这种‘密度对齐’与‘描述增强’的结合，才是增强稀疏特性的物理本质。”
