# 摘要

LiDAR 检测近距离物体准确率高，对较远的物体，采样得到的是稀疏的点云数据，对目标检测造成了挑战

提出例一种知识引导的双流特征增强点生成网络-KG-DFPG, 以提高不完整物体的检测精度


# 引言
LiDAR 由于通过点云提供的 3 D 空间信息，凭借其出色的鲁棒性和目标分离能力，称为 3 D 检测的主流传感器

仍然有挑战。户外环境中，==靠近传感器的物体能够捕获更完整的几何信息，远处的物体通常有稀疏的点云数据表示==。

==LiDAR 获取的点云并非真正的 3 D ，激光无法获得扫描面后面的形状信息。==

这些因素导致捕获物体的点云结构不完整，从而降低了物体定位的准确性

**近期相关研究**
传统的方法无法从根本上解决因距离或遮挡导致的点云结构破坏问题

今年来有通过点云补全的方法重建整个物体结构提升检测性能而广泛关注。然而现有方法，先通过学习形状先验并手动添加伪点实现点云补全。或者利用预训练补全网络生成稠密的点云以恢复物体结构。

这些方法忽视了感知场景中关键结构细节，例如点密度或前景概率，或是缺乏对稠密物体结构的先验知识。

因此这些方法无法捕捉精心的物体结构，由此产生的点分布导致回归框和真实值之间出现显著偏差

# 相关工作
## 基于 LiDAR 的 3 D 目标检测
分为三类：
- 基于点的方法
- 基于体素的方法
- 点-体素结合的方法

对远处目标点云不完整及遮挡问题，稳定检测精度仍具挑战

## 用于目标检测的知识蒸馏
从教师模型传递知识，传递学生模型的特征表示能力

SparseKD 在教师预测的关键位置进行蒸馏，通过引导初始化压缩学生模型；

DistllBEV 利用教师预测区分前景|背景并传递关键区域的知识

RadarDistill 借助 LiDAR 增强稀疏毫米波雷达特征。

我们的方法通过==前景过滤实现自适应知识传递==，补充缺失的结构细节，利用更丰富的空间信息引导特征生成

## 面向 3 D 物体检测的点生成
长距离和遮挡导致的不完整点云对精确的 3 D 检测构成了主要挑战。近期研究通过增加 LiDAR 场景点密度优化物体结合结构，以提升检测效果：

SPG 通过在估计的前景区域生成语义点完成点云，以恢复物体形状；

MSMDFusion 和 MVP 利用 RGB 图像语义信息生成额外的伪点云





# 方法



## 热图引导的RPN
使用热图预测引导骨干网络关注物体轮廓和空间分布，增强候选框定位能力并为点补全提供形状线索


3 D 主干网络共有 4 层，把后三层的体素特征映射会原始体素，然后连接原始体素坐标和后三层映射回来的特征，将其输入多层感知机以生成体素热力图响应 $H_{pre}$。把物体外部的背景体素，热力图响应设为 0，对前景体素，其标签设置为为渐进标签，靠近物体中心点的点标签接近 1，越靠近物体边界的点，标签逐渐接近 0，但不为 0, 得到 $H_{tru}$

使用 SmoothL 1 损失函数计算二者的损失



## 前景感知特征蒸馏

先验知识帮助模型感知完整的物体结构。前景感知模块，自适应的从密集点云中转移只是，恢复缺失的结构信息，并引导原始点云生成空间信息丰富的特征

教师模型的训练，在数据集中搜索形似的实例，将他它和原始点云融合，得到密集点云对象，按照边界框的类别位置信息进行对其，训练得到所有教师模型

冻结教师模型的权重，并用于初始化学生网络。最后使用稀疏点云作为输入训练学生网络，分别使用两个网络输出的特征进行类别预测，预测点的类别

基于教师模型的预测结果，生成指示参数，用于区分前景和背景候选框，把感兴趣区域的前景过滤出来

Loss 分为三个部分，
1. 对其教师和学生网络类别预测的 L oss，使用交叉熵
2. 细粒度层面特征一致性的 Loss，使用MSE
3. 指导学生在网络分布层面上学习教师特征的整体空间结构的 Loss，使用MMD 损失（应该是预测候选框对齐用的）



## 动态体素 RoI 池化

使用预测的热力图和点密度进行动态特征提取，并将像点云密度和体素前景概率等结构细节编码到体素特征中，增强物体拓扑感知能力


首先，对热力图预测进行下采样以生成形状热图，并把它和特征层拼接，生成增前的特征，用于后续的特征提取，之后进行 RoI 池化操作

使用核密度估计（KDE）来计算每个体素的局部密度
