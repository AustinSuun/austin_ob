在 Pandas 中打开和查看文件（如 CSV、Excel、TSV 等）通常使用以下几条命令：

---

### ✅ 1. 读取文件（常见格式）

|文件类型|命令|
|---|---|
|**CSV 文件**|`pd.read_csv("filename.csv")`|
|**Excel 文件**|`pd.read_excel("filename.xlsx")`|
|**TSV 文件**（以 tab 分隔）|`pd.read_csv("filename.tsv", sep="\t")`|
|**纯文本（自定义分隔符）**|`pd.read_csv("filename.txt", sep=",")`（或其它分隔符）|

```python
import pandas as pd

# 例：读取 CSV 文件
df = pd.read_csv("data.csv")
```

---

### ✅ 2. 查看文件内容

```python
df.head()        # 查看前5行
df.tail()        # 查看最后5行
df.sample(5)     # 随机查看5行
df.shape         # 查看行数和列数
df.columns       # 查看所有列名
df.info()        # 简要信息（数据类型、缺失值等）
df.describe()    # 数值型列的统计信息
```

---

### ✅ 补充：编码问题

有些文件是 GBK 编码（特别是中文），可能需要指定编码：

```python
df = pd.read_csv("file.csv", encoding="gbk")
```
