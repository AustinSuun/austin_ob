### 3.1 Preliminaries: Mamba-2 and Structured State Space Duality

尽管经典的状态空间模型（SSMs）在序列建模上表现出色，但其递归计算在现代硬件（如 GPU）上的效率受限。**Mamba-2** [?] 引入了 **结构化状态空间对偶 (Structured State Space Duality, SSD)**，建立了 SSM 与线性注意力（Linear Attention）之间的理论联系，从而实现了更高效的矩阵乘法计算。

给定一个输入序列 $x \in \mathbb{R}^{L \times D}$，传统的 SSM 离散化方程为：

$$h_t = A h_{t-1} + B x_t, \quad y_t = C h_t$$

其中 $A, B, C$ 是系统参数。Mamba-2 证明了该递归过程等价于一个半可分离矩阵（semi-separable matrix）变换。通过这种对偶性，输出 $Y$ 可以通过矩阵乘法直接计算：

$$Y = \text{SSD}(X, A, B, C) = \text{Mask}(Q K^\top) \cdot V$$

这里，$Q, K, V$ 是 $X$ 的线性投影。与标准的二次注意力机制不同，SSD 施加了一个因果掩码（Causal Mask），并通过 1D 半可分离结构将计算复杂度降低至 线性 $O(L)$。

在 Gravity-Mamba 中，我们利用 Mamba-2 作为核心算子。这种设计不仅继承了线性复杂度的优势，还通过张量并行（Tensor Parallelism）极大地加速了大规模点云特征的训练与推理。

- **输入表示 (Input Representation):** 原始点云首先被体素化（Voxelization），生成稀疏体素张量。

### 3.3 Gravity Streamline Mapping (GSM)

现有的 3D SSM 方法主要依赖希尔伯特曲线等几何排序，这种排序对语义内容是盲目的。为了确保 Mamba-2 引擎优先处理高信息量区域，我们提出了 **重力流线映射 (Gravity Streamline Mapping, GSM)**。

1. 特征质量定义 (Definition of Feature Mass).

受物理学启发，我们将特征响应的强度定义为“质量（Mass）”。对于第 $i$ 个体素，其质量 $m_i$ 计算为其特征通道的 $L_1$ 范数或最大响应值：

$$m_i = \| f_i \|_1$$

这意味着高响应区域（通常是物体前景）拥有更大的质量，从而在特征空间中产生更强的“引力”。

2. 语义流线生成 (Semantic Streamline Generation).

我们构建一个基于质量的排序索引 $\mathcal{I}$。不同于静态的 $XYZ$ 坐标排序，GSM 根据质量梯度对体素进行重排。排序策略遵循以下原则：

$$\mathcal{I} = \text{Argsort}_{\text{descending}}( \mathcal{G}(m) )$$

其中 $\mathcal{G}$ 是一个分组函数，它首先根据局部引力将点聚类为若干个语义“流域（Basins）”，然后在流域内部按质量降序排列。

这种策略产生了一条动态的“流线”，确保输入序列 $X_{seq}$ 总是从物体核心（高质量）流向背景上下文（低质量）。这使得 Mamba-2 的因果掩码能够更有效地在相关语义片段之间传递信息，减少了稀疏空洞带来的干扰。

### 3.4 Gravity-Mamba Block

这是网络的基本构建单元。在通过 GSM 获取语义有序的序列 $X_{gsm}$ 后，我们将其送入 Mamba-2 模块。

$$X' = \text{RMSNorm}(X_{gsm})$$

$$X_{out} = \text{Linear}( \text{SSD}( \text{Linear}(X') ) ) + X_{gsm}$$

在该模块中，输入首先经过归一化和线性投影生成 $A, B, C$ 及 $X$ 的输入，然后进入 SSD 算子 进行高效的时间序列建模。由于输入序列已经通过 GSM 进行了语义优化，SSD 的线性注意力机制能够更精准地捕捉物体内部及其周围的上下文依赖，而无需在无关的空白体素上浪费计算资源。

### 3.5 Ray-Gravity Guided Expansion (RGGE)

为了解决 LiDAR 点云的“仅表面（Surface-only）”特性导致的内部空洞问题，我们在解码器阶段引入了 **射线重力引导的拓展 (Ray-Gravity Guided Expansion, RGGE)** 模块。该模块旨在恢复物体的体积几何信息。

1. 射线-几何建模 (Ray-Geometric Modeling).

对于每个非空体素 $p_i$，我们计算两个关键向量：

- **射线向量 (Ray Vector) $\vec{v}_{ray}$:** 从 LiDAR 原点指向点 $p_i$ 的单位向量，代表物理上的入射方向。
    
- **几何法向 (Geometric Normal) $\vec{n}_{geo}$:** 基于局部邻域估计的表面法向量，用于约束拓展方向，防止噪声溢出。
    

2. 物理感知拓展 (Physics-aware Expansion).

RGGE 沿射线方向向物体内部生成新的特征点，以填充空洞。拓展方向 $\vec{d}_{exp}$ 由射线向量主导，并受到几何约束的修正：

$$\vec{d}_{exp} = \text{Normalize}( \vec{v}_{ray} - \lambda (\vec{v}_{ray} \cdot \vec{n}_{geo}) \vec{n}_{geo} )$$

其中 $\lambda$ 是控制表面约束强度的系数。随后，我们沿 $\vec{d}_{exp}$ 方向在步长 $\delta$ 处生成 $K$ 个新的特征点：

$$p_{new}^{(k)} = p_i + k \cdot \delta \cdot \vec{d}_{exp}, \quad k \in \{1, ..., K\}$$

这些新生成的点被赋予了从表面点衰减的特征值，有效地模拟了物体内部的体积特征。这不仅增加了点云的密度，还为下游检测头提供了更完整的几何结构支撑。

# 3. Methodology

In this section, we present **Gravity-Mamba**, a physics-inspired backbone designed for efficient and structure-aware 3D point cloud representation. We first briefly review the preliminaries of Mamba-2 and Structured State Space Duality in **Sec. 3.1**. We then illustrate the overall architecture in **Sec. 3.2**. To address the limitations of static geometric serialization, we detail the **Gravity Streamline Mapping (GSM)** in **Sec. 3.3**. Subsequently, we describe the core Gravity-Mamba Block in **Sec. 3.4**. Finally, we introduce the **Ray-Gravity Guided Expansion (RGGE)** module in **Sec. 3.5**, which leverages physical constraints to recover internal object geometry.

### 3.1. Preliminaries: Mamba-2 and Structured State Space Duality

While classic State Space Models (SSMs) excel at sequence modeling, their recursive computation can be inefficient on modern hardware. **Mamba-2** [?] introduces **Structured State Space Duality (SSD)**, establishing a theoretical bridge between SSMs and linear attention, thereby enabling highly efficient matrix multiplication operations.

Given an input sequence $x \in \mathbb{R}^{L \times D}$, the continuous system is governed by $h'(t) = \mathbf{A}h(t) + \mathbf{B}x(t)$. After discretization, the recursive process in Mamba-2 is proven to be equivalent to a semi-separable matrix transformation. Through SSD, the output $Y$ can be computed non-recursively via a dual form resembling linear attention:

$$Y = \text{SSD}(X, \mathbf{A}, \mathbf{B}, \mathbf{C}) = \text{Mask}(\mathbf{Q} \mathbf{K}^\top) \cdot \mathbf{V}$$

Here, $\mathbf{Q}, \mathbf{K}, \mathbf{V}$ are linear projections of the input $X$. Unlike standard quadratic attention, SSD imposes a causal mask and leverages the semi-separable structure to reduce computational complexity to linear time $O(L)$. In Gravity-Mamba, we leverage Mamba-2 as the core operator. This design not only inherits linear complexity but also facilitates Tensor Parallelism, significantly accelerating training and inference for large-scale point cloud features.

### 3.2. Overall Architecture

As illustrated in **Figure 2**, Gravity-Mamba adopts a U-Net style symmetric Encoder-Decoder architecture designed to extract multi-scale features from sparse data.

- **Input Representation:** The raw point cloud is first voxelized to generate a sparse voxel tensor.
    
- **Encoder:** The encoder comprises four stages. In each stage, the 3D sparse voxels are first dynamically flattened into a 1D sequence via **GSM**, then processed by stacked **Gravity-Mamba Blocks** to extract contextual features, and finally downsampled via strided sparse convolution.
    
- **Bottleneck:** At the deepest level, we utilize SSD layers to capture global long-range dependencies with a full receptive field.
    
- **Decoder:** The decoder symmetrically recovers spatial resolution. The proposed **RGGE** module is integrated into the feature recovery stage to physically enhance the geometric completeness of objects before the final detection head.
    

### 3.3. Gravity Streamline Mapping (GSM)

Existing 3D SSM approaches predominately rely on fixed geometric orderings (e.g., Hilbert curves), which are blind to semantic content. To ensure the Mamba-2 engine prioritizes high-information regions, we propose **Gravity Streamline Mapping (GSM)**.

1. Definition of Feature Mass.

Drawing inspiration from physics, we define the intensity of feature response as "Mass." For the $i$-th voxel, its mass $m_i$ is calculated as the $L_1$-norm (or maximum response) of its feature channels:

$$m_i = \| f_i \|_1$$

This implies that high-response regions—typically object foregrounds—possess larger mass, thereby exerting stronger "gravitational pull" in the feature space.

2. Semantic Streamline Generation.

We construct a mass-based sorting index $\mathcal{I}$. Unlike static $XYZ$ sorting, GSM rearranges voxels based on the gradients of mass. The sorting strategy follows:

$$\mathcal{I} = \text{Argsort}_{\text{descending}}( \mathcal{G}(m) )$$

where $\mathcal{G}$ represents a grouping function that clusters points into local semantic "basins" based on local gravity, and then sorts them by mass within each basin.

This strategy generates a dynamic "streamline," ensuring that the input sequence $X_{seq}$ always flows from Object Cores (High Mass) to Background Context (Low Mass). This allows the causal mask in Mamba-2 to propagate information effectively among semantically related segments, minimizing interference from sparse voids.

### 3.4. Gravity-Mamba Block

This is the fundamental building unit of our backbone. After obtaining the semantically ordered sequence $X_{gsm}$ via GSM, we feed it into the Mamba-2 module.

$$X' = \text{RMSNorm}(X_{gsm})$$

$$X_{out} = \text{Linear}( \text{SSD}( \text{Linear}(X') ) ) + X_{gsm}$$

In this block, the input undergoes normalization and linear projection to generate the $\mathbf{A}, \mathbf{B}, \mathbf{C}$ parameters and the input for the SSD operator. Since the input sequence is semantically optimized by GSM, the linear attention mechanism of SSD can accurately capture contextual dependencies within and around objects without wasting computational resources on irrelevant empty voxels.

### 3.5. Ray-Gravity Guided Expansion (RGGE)

To address the "surface-only" characteristic of LiDAR data which leaves object interiors hollow, we introduce the **Ray-Gravity Guided Expansion (RGGE)** module in the decoder stage. This module aims to recover volumetric geometric information.

1. Ray-Geometric Modeling.

For each non-empty voxel $p_i$, we compute two key vectors:

- **Ray Vector $\vec{v}_{ray}$:** A unit vector pointing from the LiDAR sensor origin to the point $p_i$, representing the physical direction of incidence.
    
- **Geometric Normal $\vec{n}_{geo}$:** The surface normal vector estimated from the local neighborhood, serving as a constraint to prevent noise overflow.
    

2. Physics-aware Densification.

RGGE generates new feature points extending into the object's interior to fill voids. The expansion direction $\vec{d}_{exp}$ is dominated by the ray vector and corrected by geometric constraints:

$$\vec{d}_{exp} = \text{Normalize}( \vec{v}_{ray} - \lambda (\vec{v}_{ray} \cdot \vec{n}_{geo}) \vec{n}_{geo} )$$

where $\lambda$ is a coefficient controlling the strength of the surface constraint. We then generate $K$ new feature points along $\vec{d}_{exp}$ with step size $\delta$:

$$p_{new}^{(k)} = p_i + k \cdot \delta \cdot \vec{d}_{exp}, \quad k \in \{1, ..., K\}$$

These newly generated points are assigned decayed feature values from the surface point, effectively simulating internal volumetric features. This process not only increases point density but also provides a more complete geometric representation for downstream feature learning.
