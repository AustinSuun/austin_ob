# 第一步、使用cc-switch配置api

可以从 __Q群 513479198__ ，下载  软件 cc-switch

或者从github 网站下载 [cc-switch/](https://github.com/farion1231/cc-switch/releases)

## 按顺序点击打开软件

![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20260524203125947.png)


## 打开后如下图，向下滑动找到要填写的配置项
![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20260524203229001.png)
![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20260524203546376.png)

## 供应商名称填：星群AI
## API请求地址填写
  ```
  https://ai.crantor.xyz/v1
  ```

## API  Key

API Key 需要在网站生成一下


打开网站，左侧的API密钥

![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20260524203824610.png)

填写好密钥名称（自己起一个名字），选择分组

![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20260524204144706.png)

创建完成后将生成的API密钥复制到cc-switch的API

![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20260524204238070.png)


设置完成，之后点击添加，然后启用一下，就完成了设置
![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20260524204540237.png)

# 第二步、使用codex

配置完成之后就可以直接在 __桌面版codex、codex CLI、codex vscodex 插件__ 三种方式中使用最新的GPT模型啦！

大家自行选择使用方式！

## 桌面版codex 下载

下载好桌面版软件，打开就可以正常使用啦！

[codex桌面版下载](https://openai.com/zh-Hans-CN/codex/)

## codex CLI

codex CLI 有github仓库，在界面介绍中有下载命令！

[codex CLI github](https://github.com/openai/codex)

## VS code 插件

插件市场中搜索codex, 安装就可以使用了！

打开一个项目文件，右上角有一个gpt图标，点击就出现对话框了！
