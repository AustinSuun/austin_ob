# Mamba 3 D 概述
Mamba 在序列数据中表现出惊人的效果，但适配搭配 3 D 点云并非易事。

Mamba 的全局感受野无法充分捕捉==局部几何结构==，限制了其学习细粒度特征的能力为解决上述问题提出了 Mamba 3 D，其中包含一个高效的==局部归一化池化（LNP）模块==用于显示提取局部几何信息，以及一种转为无序点设计的==双向SSM（bi-SSM）==


# LNP-局部归一池化

## K-归一化：传播

首先对 K 近邻采样点的特征做归一化处理，然后把 K 近邻采样点特征拼接上中心点特征。再乘上系数 $\gamma$ 加上偏置 $\beta$

![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20250921110053178.png)

## K-pooling
在局部图传播特征之后，将信息聚合回中心点，以进行特征更新。最大池化常用于特征聚合以保持顺序不变性，但是他会导致丢失信息。==受 SoftMax 启发==，引入了 K-pooling，以缓解信息丢失的同时高效的执行局部特征聚合

# 双向SSM
Mamba 最初的设计为适用于处理一维序列的单向模型。然而视觉任务通常需要对全局空间信息的理解。一次 VisionMamba 提出同时使用==前向和后向 SSM，通过简单的水平翻转==标记顺序来整合全局信息，即文本顺序反向

然而，与图像结构化网格不同，点云是无序且不规则的，学习序列顺序会导致不可靠且不稳定的伪顺序依赖性。为了解决这一问题，建议优先建模特征向量的内在反而步，而非点标记。具体来说，提出一种==新的后向SSM==, 称为==特征逆向SSM==，或 C-SSM,. 将其与 Mamba 中的原始的前向SSM (L+SSM)结合，便构成了双向 SSM 模块，建成 bi-SSM

![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20250921121542041.png)

垂直翻转通道获得 $F^{C-}$，这种方法==减少了伪顺序的依赖性==，在无序点云中尤为重要，因为令牌顺序缺乏一致意义。例如，两个相邻 token 可能分别表示飞机的尾部和头部，他们在空间和语义上相距甚远，这对连续且完整的特征学习提出了挑战。

Mamba 的特征选择机制可能家具这一问题，使特征分散在高维空间中。相反，通过对==特征通道进行翻转==，模型==优先学习特征向量的分布==。这两个方向--前向 token 嵌入和后向特征通道--包含不同且更可靠的信息，从而增强 Mamba 3 D 获取更有效知识的能力



# 预训练细节
可以从头开始训练，也可以预训练，文中验证了 Oiubt-Bert 和 Point-MAE 提出的两种常用预训练策略的效果

## Point-BERT 预训练
随机屏蔽 55%~85%的输入点嵌入，而不是-Point-BERT 中的 $[0.25, 0.45]$ 之间的屏蔽比例。提高屏蔽比例可以较快训练过程，还能增强 MAMBA 3 D 的学习能力，是模型能够从有限的输入中学习。然后，MAMBA 3 D 编码器处理可见和被屏蔽的嵌入以生成标记序列。同时直接使用 Poit-BERT 预训练的 dVAE 权重，从点嵌入中预测标记序列作为标记引导。最后，计算编码器输出标记序列与 dVAE 生成序列之间的 L 1 损失，作为损失函数

## Point-MAE 预训练策略
沿用 Point-MAE 的法官法，使用掩码点建模方法，直接重建被掩码的点。采用编解码器架构，其中编码器金处理可见标记，并生成其编码。与 Point-MAE 不同，我们的解码器使用了与编码器不同的架构，仅包含双向 SSM 模块不包含 LNP 模块，这可以在不损失性能的情况下加快收敛。编码后的可见标记和掩码标记被输入解码器以预测掩码点。损失通过输出点和真实点之间的 Chamfer 距离计算。在下游任务中，仅使用预训练的编码器提取特征，并附加任务头进行微调
