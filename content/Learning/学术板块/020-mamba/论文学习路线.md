## 📚 学习路径建议

### 1️⃣ 基础知识准备

首先需要掌握：

- **State Space Models (SSM)** 基础
- **RNN/LSTM** 原理
- **Transformer** 架构理解
- **线性代数**（状态空间表示）

### 2️⃣ 循序渐进学习

**阶段一：理论理解**

1. 阅读 Mamba 原论文
2. 学习前置论文：
    - S4: "Structured State Spaces for Sequence Modeling"
    - HiPPO: "Recurrent Memory with Optimal Polynomial Projections"

**阶段二：实践理解** 3. 查看官方 GitHub 代码：https://github.com/state-spaces/mamba 4. 尝试简单的 PyTorch 实现 5. 运行官方示例

**阶段三：深入应用** 6. 在具体任务上测试 Mamba 7. 与 Transformer 对比实验

### 3️⃣ 学习资源推荐

**在线资源**：

- A Visual Guide to Mamba and State Space Models
- Understanding Mamba and Selective State Space Models
- YouTube 上的讲解视频

**实践资源**：

- HuggingFace 上的 Mamba 模型

- Kaggle 上的相关 notebooks

### 4️⃣ 学习重点

重点理解这几个核心概念：

- **选择性机制** (Selectivity)
- **状态空间模型**的离散化
- **线性时间复杂度**如何实现
- 与 Transformer 的本质区别
