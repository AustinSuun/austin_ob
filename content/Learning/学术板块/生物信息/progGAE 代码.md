# Process-数据处理部分
你这段代码主要做了以下数据处理步骤，涉及的 **Pandas 和统计学方法**，总结如下：

---

## 代码具体做了什么处理？

1. **std_filter(number)**
    
    - 计算每列（每个特征）的标准差（`self.data.std()`），
        
    - 按标准差从大到小排序，
        
    - 取出标准差最大的前 `number` 列，
        
    - 返回只包含这些列的新数据集。  
        **作用：筛选出“波动较大”的特征**，常用来去除低变异（低信息量）列。
        
2. **MinmaxVARIABLES(number)**
    
    - 先调用上面 `std_filter(number)` 筛选列，
        
    - 对筛选后的数据按列做 Min-Max 归一化，转换到 [0, 1] 区间：
        
        Xnorm=X−min⁡(X)max⁡(X)−min⁡(X)X_{norm} = \frac{X - \min(X)}{\max(X) - \min(X)}
    
    **作用：把特征缩放到同一尺度，方便后续计算。**
    
3. **sort_corr(number)**
    
    - 先调用 `MinmaxVARIABLES(number)` 得到归一化数据，
        
    - 计算归一化数据的相关系数矩阵（`data.corr()`），再取绝对值（`abs()`），
        
    - 对相关系数矩阵做累积乘积（`cumprod()`），然后开 n 次方根（这里 n 是相关系数矩阵的维度），
        
    - 按最后一列的值排序，返回排序后的列顺序对应的数据。
        

这个操作较复杂，目的是用一种加权或综合相关度指标，  
**对特征按相关性强弱排序**，优先保留与其它特征高度相关的特征列。

---

## 用到了哪些 Pandas 和数学方法？

|操作|Pandas/数学方法|说明|
|---|---|---|
|标准差计算|`self.data.std()`|计算每列标准差|
|排序并选取前几列|`sort_values()` + `index`|按标准差排序并取前 N 个特征列|
|最小-最大归一化|`(data - data.min()) / (data.max() - data.min())`|线性缩放到 [0,1]|
|计算相关系数矩阵|`data.corr()`|计算皮尔森相关系数矩阵|
|绝对值|`.abs()`|取相关系数的绝对值，忽略正负号|
|累积乘积|`.cumprod()`|对矩阵按行或列累积连乘|
|开 n 次方根（幂运算）|`** (1 / n)`|取几何平均|
|排序索引|`.sort_values()` + `.index`|对结果排序并获得对应列名|

---

## 这段代码的**核心数据处理逻辑**总结：

- **先根据标准差筛选变量**（变异度高，信息量大）
    
- **再做归一化**（统一量纲）
    
- **最后根据相关系数的“几何平均”大小，对变量排序**，保留相关度较强的特征列
    

---

> **该代码通过筛选标准差高的特征并做归一化，再用相关系数的几何平均来排序特征，达到优选高变异且相关性强的特征列的目的。**
