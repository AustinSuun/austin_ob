**过去 5 年（大致 2021–2025）内** 关于 **纯点云 / LiDAR 的 3D 目标检测（在恶劣天气下）** 领域中较重要的论文、数据集、仿真方法和综述式资源——每条都带简短说明和来源，方便你快速入门与跟进研究。

# 核心论文 / 数据集与方法（精选）

1. **SemanticSTF — adverse-weather LiDAR 数据集（CVPR 2023）**  
    引入了带密集点级标注的恶劣天气（雨、雾、雪）LiDAR 数据，用于研究在“真实/非理想”天气下的点云语义/感知问题，是点云在恶劣天气研究的重要基线数据集之一。 ([CVF开放获取](https://openaccess.thecvf.com/content/CVPR2023/papers/Xiao_3D_Semantic_Segmentation_in_the_Wild_Learning_Generalized_Models_for_CVPR_2023_paper.pdf?utm_source=chatgpt.com "3D Semantic Segmentation in the Wild: Learning Generalized ..."))
    
2. **LiDAR Snowfall Simulation for Robust 3D Object Detection**  
    提出物理/半物理的雪模拟方法，把晴天真实 LiDAR 扫描变换为模拟下雪情形，用于训练/评估 3D 检测器在降雪下的鲁棒性（能直接用于生成带雪的训练样本）。 ([light.princeton.edu](https://light.princeton.edu/publication/lidar-snowfall-simulation-for-robust-3d-object-detection/?utm_source=chatgpt.com "LiDAR Snowfall Simulation for Robust 3D Object Detection"))
    
3. **LiDAR point-cloud augmentation / conditional augmentation for adverse conditions（MDPI 2024）**  
    提出点云级的增广方法与条件引导，专门用于扩充/模拟恶劣天气下的 LiDAR 数据，以提升在稀缺恶劣天气样本下模型的泛化。 ([MDPI](https://www.mdpi.com/2072-4292/16/12/2247?utm_source=chatgpt.com "LiDAR Point Cloud Augmentation for Adverse Conditions ..."))
    
4. **GIC-Net：Geometric Information Constraint for detection under adverse weather（2024）**  
    针对恶劣天气导致的点云质量下降，提出基于几何信息约束的检测网络以提高鲁棒性（针对 LiDAR 点云的建模/约束方法）。 ([科学直达](https://www.sciencedirect.com/science/article/pii/S0968090X24000767?utm_source=chatgpt.com "Geometric information constraint 3D object detection from ..."))
    
5. **评估/基线类工作：3D 检测在恶劣天气下的性能退化分析（若干工作，2023–2025）**  
    多篇工作分析了现有 LiDAR-only 检测器在雨/雾/雪下的性能下降，并给出量化基线（包括学术测评与合成数据评估）。这些评估对理解问题空间非常有用。示例参见综述/评测文章与会议论文。 ([NHSJS](https://nhsjs.com/2024/3d-lidar-based-object-conditions-in-adverse-weather-conditions/?utm_source=chatgpt.com "3D Lidar-Based Object Conditions in Adverse Weather ..."))
    
6. **（相关但为多模态/对比）4D-radar 与 LiDAR 融合以提升恶劣天气鲁棒性（CVPR/ECCV/ArXiv 2024）**  
    虽然不是“纯点云”方法，但这些工作（如 ECCV 2024 / CVPR 2024 的几篇）展示了在恶劣天气下用雷达补偿 LiDAR 失能的方向，对比参考意义很强（说明纯 LiDAR 的局限与可行的增强路线）。 ([ECVA](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/07349.pdf?utm_source=chatgpt.com "LiDAR-based All-weather 3D Object Detection via ..."))
    
7. **Weather-KITTI / Weather-NuScenes 等合成/增强数据集与工具链（开源仓库）**  
    社区有若干开源仓库和工具（如 Weather-KITTI、Weather-NuScenes）用于把标准数据集合成为雨/雾/雪版本，便于在相同注释下做鲁棒性比较。也有专门为“去噪/去天气点”训练的模型实现（例如 TripleMixer 仓库中集成的一些数据/方法）。 ([GitHub](https://github.com/Grandzxw/TripleMixer?utm_source=chatgpt.com "[TIP 2025] TripleMixer: A 3D Point Cloud Denoising Model ..."))
    

# 对你做纯点云（LiDAR-only）研究的实用建议

- **优先数据集**：SemanticSTF（真实恶劣天气标注）是首选基线；若需要大规模训练，补上 Weather-KITTI/Weather-NuScenes（合成）可快速扩数据量。 ([CVF开放获取](https://openaccess.thecvf.com/content/CVPR2023/papers/Xiao_3D_Semantic_Segmentation_in_the_Wild_Learning_Generalized_Models_for_CVPR_2023_paper.pdf?utm_source=chatgpt.com "3D Semantic Segmentation in the Wild: Learning Generalized ..."))
    
- **仿真工具**：使用 LFS（fog sim）、LSS（snow sim）和 LISA（rain augment）这类仿真/增广模块，能把晴天扫描转为多种天气，便于做 controlled experiments。 ([arXiv](https://arxiv.org/html/2408.13802v2?utm_source=chatgpt.com "A 3D Point Cloud Denoising Model for Adverse Weather"))
    
- **研究方向（可切入点）**：点云去噪/前处理（denoising）、鲁棒特征提取（geometry constraints）、训练时的对抗/域随机化、以及把检测器改造为对稀疏/低反射目标更稳定的架构（例如更强的局部几何编码）。 ([科学直达](https://www.sciencedirect.com/science/article/pii/S0968090X24000767?utm_source=chatgpt.com "Geometric information constraint 3D object detection from ..."))
    
- **对比/补充**：若接受多模态，4D-radar + LiDAR 融合在恶劣天气下效果显著，可作为参考或对比组。 ([CVF开放获取](https://openaccess.thecvf.com/content/CVPR2024/papers/Chae_Towards_Robust_3D_Object_Detection_with_LiDAR_and_4D_Radar_CVPR_2024_paper.pdf?utm_source=chatgpt.com "Towards Robust 3D Object Detection with LiDAR and 4D ..."))
