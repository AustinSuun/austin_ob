# 背景动机

**核心问题**
1. 计算效率
	主要是卷积核的计算问题，需要计算 A 的高次幂

2. 内存消耗
	长序列的卷积核很大，需要存储巨大的卷积核

**核心创新**
不直接计算 $A^k$，而是利用矩阵的对角加低秩（DPLR）结构

**HiPPO 到 S 4 的演进**
HiPPO：$A=-nn^T+D$
S 4：$A=Λ - PQ^T$

$Λ$：对角矩阵（复数特征值）
$P,Q$：低秩矩阵

**优势**
数值稳定性：负数对角化避免了实数矩阵的病态问题
计算效率：可以用快速算法计算卷积核


# DPLR 参数化 

由于 HiPPO 的形式限制了表达能力

**S 4 的核心创新：DPLR**
DPLR=Diagonal Plus Low-Rank
对角+低秩

将状态矩阵参数化为：
$$
A=Λ-PQ^T
$$
其中 $Λ=diag(\lambda_{1}, \lambda_{2},\dots,\lambda_{N})$：对角矩阵
$P,Q$ 低秩矩阵（秩为R）

**与 HiPPO 的关系**
HiPPO 是秩为 1 的特殊情况

S 的 DPLR 的形式是更一般化的，秩可以是R

**关键优势**
更强的表达能力：不局限与 HiPPO 的固定结构
复数参数化：$\lambda_{i}$ 可以是负数，更稳定
可学习参数：$Λ,P,Q$ 可以通过梯度下降学习


**初始化策略**
Λ 直接使用 HiPPO 的对角矩阵 $[1,3,5\dots]$
$P,Q$ 直接使用 $\sqrt{ 2n+1 }$, 根 1，根 3，根 5

**复数拓展和数值稳定**

HiPPO 给出的实数特征值在深度学习中不稳定, 如果值>1，计算高次幂时数值会爆炸
解决：负数拓展+共轭设计
对角矩阵的对角上的元素由
Lambda = 5

改为

Lambda = -5 + 0 i  # 负实部确保 A^k 衰减而不是增长

实数部分加上了负数; 负数部分的的特征值可以表达震荡模式

物理含义：实数部分控制时间素的
虚数部分控制震荡频率

不同的序列模式需要不同的记忆通道
低频通道捕捉长期趋势
高频通道捕捉快速变化

**保证输出是实数输出，使用共轭对**

复数特征值会导致输出也是复数

解决方案：使用共轭特征值

```
lambda_1 = -1 + 2i    # 第一个
lambda_2 = -1 - 2i    # 它的共轭对
```

上述两复数相加，虚数部分就会抵消

创建的时候，lambda 只创建一半；另一半是共轭
然后两部分拼接

```
def create_conjugate_pairs(N):
    assert N % 2 == 0
    
    # 只创建一半，另一半自动为共轭
    half_N = N // 2
    lambda_half = -torch.ones(half_N) + 1j * torch.pi * torch.arange(half_N)
    
    # 拼接共轭对
    Lambda = torch.cat([lambda_half, torch.conj(lambda_half)])
    return Lambda
```

**P、Q 的对称共轭设计**

不只特征值 lambda 需要配对，P、Q 也需要配对
```
# 如果特征值配对：
Lambda = [λ₁, λ₁*, λ₂, λ₂*, ...]

# 那么P、Q也必须配对：
P = [p₁, p₁*, p₂, p₂*, ...]
Q = [q₁, q₁*, q₂, q₂*, ...]
```

也是为了整个系统输出的是实数

```
def init_conjugate_pq(N):
    # 基于HiPPO的实数初始化
    p_real = torch.sqrt(2 * torch.arange(N) + 1)
    
    # 转为复数并构造共轭对
    half_N = N // 2
    P_half = p_real[:half_N].to(torch.complex64)
    P = torch.cat([P_half, torch.conj(P_half)]).unsqueeze(1)
    
    Q = P.clone()  # Q与P相同
    return P, Q
```

**S 4 初始化完整步骤**
```
def init_s4_complete(N):
    """S4的完整初始化流程"""
    assert N % 2 == 0, "N必须是偶数"
    
    # Step 1: 基于HiPPO创建实数基础
    n = torch.arange(N // 2, dtype=torch.float)
    
    # Step 2: 构造稳定的复数特征值
    real_parts = -(2 * n + 1)  # 负实部，确保稳定
    imag_parts = torch.pi * n  # 虚部，提供频率
    
    # Step 3: 创建共轭对
    lambda_positive = real_parts + 1j * imag_parts
    Lambda = torch.cat([lambda_positive, torch.conj(lambda_positive)])
    
    # Step 4: 对应的P、Q共轭对
    p_base = torch.sqrt(2 * torch.arange(N) + 1)
    P_half = p_base[:N//2].to(torch.complex64)
    P = torch.cat([P_half, torch.conj(P_half)]).unsqueeze(1)
    Q = P.clone()
    
    return Lambda, P, Q
```

```
# S4: A = Λ - PQ^T     (复数，稳定，可学习)
```


**高效计算算法**

问题：复数 DPLR 计算复杂度
现在有了负数参数 $A=Λ -PQ^T$, 但是如何高效计算SSM

朴素方法，即 HiPPO 中的方法，计算卷积核，序列中每有一个元素，就需要多进行一次矩阵乘法; 时间复杂度 $O(L*N^2)$，太慢了

S 4 的关键洞察：避免显式矩阵乘法
由于 $A=Λ -PQ^T$ 的特殊结构，可以

不直接计算 $A^K$ 而是利用结构化计算


**S 4 快速计算公式**
核心公式：避免矩阵幂

对于 $A=Λ -PQ^T$, 计算 $CA^kB$ 不需要显式的计算 $A^k$

递推公式（简化版）： # C @ A^k @ B = C @ Λ^k @ B - (低秩修正项)

通过递推公式，可以法线，需要计算 $Λ^k$ 和低秩修正项，$A^k$ 可以直接对角线元素逐个计算的 k 次方，而不是以矩阵的方式计算，时间复杂度 $O(n)$

低秩修正项的计算，关键先看 $Λ -PQ^T$ 的展开式

```python
# A^k = (Λ - PQ^T)^k 
#     = Λ^k - Λ^{k-1}PQ^T - ... (复杂展开)
#     
# 但我们只需要 C @ A^k @ B，不需要完整的A^k！
# 通过clever重排计算顺序，避免大矩阵运算
```

$$\begin{align}
BA^kC&=B(Λ - PQ^T)^kC \\
B(Λ^k-Λ^{k-1}PQ^T+\dots)C
\end{align}  $$

$Λ^k$ 后面的展开项就是低秩修正项的

这样低秩修正项就可以通过后面的展开项来计算，但是展开项非常多，我们可以对修正项做一个近似，如只是用一阶近似

一阶修正：近似 $-k * Λ^{k-1} @ PQ^T$ 的效应

虽然近似公式中依然有 $PQ^T$ 的形式，但是可以通过调整计算顺序避免 $PQ^T$ 的构造
近似公式：$CA^kB ≈ CΛ^kB - kCΛ^{k-1}PQ^TB$

利用结合律重排 $term2 = k * C @ (Lambda**(k-1) * (P @ (Q.T @ B)))$
先计算 $Q.T@B$，再和 P 相乘，倒着的顺序可以计算

复杂度对比
```python
# 如果构造PQ^T:
# - 存储：O(N²)
# - 计算：O(N²)

# S4的方式：
# - Q.T @ B: O(R×d)   (R很小)
# - P @ QtB: O(N×d)   
# - 逐元素运算: O(N)
# - 总计：O(N×d + R×d) ≈ O(N)
```


**并行化的关键：高效卷积**
卷积操作需要计算 $A^k$ 作为卷积核，在 HiPPO 中计算复杂度是 $O(L*n^2)$, 计算复杂度高，占内存；且因为 A 都是整数，卷积核数值不稳定，容易爆炸

S 4 实现了实际可用的卷积算法, 即上面计算 $BA^kC$ 就是卷积核，时间复杂度 $O(L*n)$

训练的时候使用卷积来并行化训练；推理时不使用卷积，但是仍然可以使用 DPLR 构造来避免显式构造 $A$



**FFT 优化**
优化的是进行卷积的操作, 直接时域卷积（正常的卷积）时间复杂度 $O(L^2)$；使用 FFT 卷积，时间复杂度 $O(L\log L)$

```python
# 在训练时，S4的完整流程： 
# 1. 计算卷积核 K = [CB, CAB, CA²B, ...] <- DPLR结构化计算优化这里
 # 2. 执行卷积 y = K * u <- FFT优化这里！
```

复杂度对比
```python
# 总复杂度 = 计算K + 执行卷积

# HiPPO原始方法：
# O(L×N²) + O(L²) = O(L×N² + L²)

# S4优化方法：
# O(L×N) + O(L log L) = O(L×N + L log L)
```
FFT 优化专门针对长序列，和 DPLR 互补

这样可以设置序列长度的阈值，长序列使用 FFT 卷积，短序列使用时域卷积（传统）

```python
# 数学原理（卷积定理）：
# 时域：y = f * g  （卷积，O(n²)）
# 频域：Y = F · G  （点乘，O(n)）

# 其中：F = FFT(f), G = FFT(g), Y = FFT(y)
```

S 4 中的时域卷积
```python
def fft_convolution(u_sequence, kernel):
    L = len(u_sequence)
    
    # 1. 时域 -> 频域
    U_freq = torch.fft.fft(u_sequence)  # 输入序列的频域表示
    K_freq = torch.fft.fft(kernel)      # 卷积核的频域表示
    
    # 2. 频域点乘（相当于时域卷积）
    Y_freq = U_freq * K_freq            # O(L) 而不是 O(L²)
    
    # 3. 频域 -> 时域
    y = torch.fft.ifft(Y_freq).real     # 逆变换得到结果
    
    return y
```


时间复杂度对比
```python
# 直接时域卷积：
for i in range(L):
    y[i] = sum(u[j] * kernel[i-j] for j in range(i))  # O(L²)

# FFT卷积：
# FFT: O(L log L)
# 点乘: O(L) 
# IFFT: O(L log L)
# 总计: O(L log L) << O(L²)
```

这里计算 A 矩阵需要求逆，为了高效求逆，使用了下面的方法
### Woodbury矩阵恒等式

$$(A + UCV)^{-1} = A^{-1} - A^{-1}U(C^{-1} + VA^{-1}U)^{-1}VA^{-1}$$

### S4中的应用

**目标**：计算 $(I + \frac{dt}{2}A)^{-1}$，其中 $A = \Lambda - PQ^T$

**重写**： $$(I + \frac{dt}{2}A)^{-1} = (I + \frac{dt}{2}\Lambda - \frac{dt}{2}PQ^T)^{-1}$$

**匹配Woodbury格式**： $$((I + \frac{dt}{2}\Lambda) + (-\frac{dt}{2}P)(I)(Q^T))^{-1}$$

其中：

- $A = I + \frac{dt}{2}\Lambda$（对角矩阵）
- $U = -\frac{dt}{2}P$，$C = I$，$V = Q^T$

**应用公式**： $$A^{-1} = \text{diag}(\frac{1}{1 + \frac{dt}{2}\lambda_i})$$

$$S = C^{-1} + VA^{-1}U = I + Q^T A^{-1}(-\frac{dt}{2}P) = I - \frac{dt}{2}Q^T A^{-1}P$$

**最终结果**： $$(I + \frac{dt}{2}A)^{-1} = A^{-1} + \frac{dt}{2}A^{-1}PS^{-1}Q^T A^{-1}$$
其中
### 与HiPPO的关键区别

#### HiPPO的处理

```python
# HiPPO: A = -nn^T + D（完整的N×N矩阵）
A_hippo = -torch.outer(n, n) + torch.diag(d)

# 离散化时：
A_d = torch.linalg.inv(I + dt/2 * A_hippo) @ (I - dt/2 * A_hippo)
# 直接对N×N矩阵求逆：O(N³) 复杂度
```

#### S4的优化

```python
# S4: A = Λ - PQ^T（DPLR结构）
# 利用Woodbury公式：
# - 主要求逆：对角矩阵 O(N)
# - 辅助求逆：R×R矩阵 O(R³)
# 总复杂度：O(N + R³) ≈ O(N)（因为R<<N）
```

### 数值效果对比

|方法|矩阵求逆|复杂度|数值稳定性|
|---|---|---|---|
|HiPPO|完整N×N|O(N³)|中等|
|S4|对角+小矩阵|O(N+R³)|高|

## S矩阵求逆的计算复杂度

### S矩阵的维度

```python
S = I + dt/2 * Q.T @ A^{-1} @ P  # S是(R × R)矩阵
```

其中：

- $Q \in \mathbb{C}^{N \times R}$
- $P \in \mathbb{C}^{N \times R}$
- 所以 $S \in \mathbb{C}^{R \times R}$

### 计算S的复杂度

```python
# 1. A^{-1}: 对角矩阵逆 - O(N)
A_inv = 1.0 / (1 + dt/2 * Lambda)

# 2. Q.T @ A^{-1}: (R × N) @ (N × N) - O(R × N)  
QT_Ainv = Q.T * A_inv.unsqueeze(0)

# 3. (Q.T @ A^{-1}) @ P: (R × N) @ (N × R) - O(R² × N)
QT_Ainv_P = QT_Ainv @ P

# 4. S矩阵构造 - O(R²)
S = torch.eye(R) + dt/2 * QT_Ainv_P

# 5. S矩阵求逆 - O(R³)
S_inv = torch.linalg.inv(S)
```

### 总复杂度分析

|步骤|操作|复杂度|
|---|---|---|
|对角逆|$A^{-1}$|$O(N)$|
|矩阵乘法1|$Q^T A^{-1}$|$O(RN)$|
|矩阵乘法2|$(Q^T A^{-1})P$|$O(R^2N)$|
|S构造|加法|$O(R^2)$|
|**S求逆**|**LU分解**|$O(R^3)$|

### R的典型取值

```python
# 在S4实践中：
R = 1  # 大多数情况，PQ^T是秩1矩阵
R = 2  # 少数情况需要秩2

# 所以S矩阵求逆的消耗：
R=1: O(1³) = O(1) - 几乎免费！
R=2: O(2³) = O(8) - 仍然很便宜！
```

### 对比总消耗

```python
# S4总的离散化复杂度：
O(N) + O(RN) + O(R²N) + O(R³) ≈ O(RN)

# 当R=1时：O(N)
# 当R=2时：O(2N) 

# vs HiPPO的O(N³) - 巨大改进！
```

**关键**：由于R通常是1或2，S矩阵求逆 $O(R^3)$ 的消耗完全可以忽略！主要消耗在 $O(RN)$ 的矩阵乘法上。
