# pointnet
参考 pointnet 的论文和实现代码，总结一下 pointnet 的相关内容
## pointnet网络结构
骨干网络主要分为两部分，两个都是空间变换网络（Spatial Transformer Network，STN）
这里对数据进行介绍，数据有两种形态，一个是只用[x, y, z]位置坐标的数据，二是还额外使用 rgb 颜色的数据，STN 3 D 网络用来生成对坐标[x, y, z]的变换矩阵，STNkd 用来生成对变换后的 xyz坐标以及原始的 rgb 数据进行变换的变化矩阵
- STN 3D
	- 输入所有通道的数据，输出针对 xyz 的变换矩阵
	- 包括 3 层1D 卷积网络和 3 层线性层，除最后一层网络，都使用 BatchNorm 1 D 和 relu 层
	- 输入的数据形状[batch_size, 点的特征维度（这里被当成通道数, 包括 rgb 通道），点的数量]
	- 在卷积完成后需要进行最大池化操作，消除点的数量维度，变成[batch_size, 卷积输出通道数]
	- 经过线性层输出形状[batch_size, 9]，之后需要对输出重塑成[batch_size, 3, 3]，其中[3, 3]是 xyz 的变换矩阵，然后让每一个 [3， 3]都加上单位矩阵
	- 这样相当于网络输出的是一个变换矩阵的偏差，再加上单位矩阵才是完整的。同时可以让训练初期，网络的输出接近单位矩阵，让网络更好学习

 STN 3 D 网络生成的变换矩阵与 xyz 相乘之后，把变换之后的 xyz 和剩下的通道拼接。
 使用 1 D 卷积将通道数拓展到 64
 如果还需要对所有特征进行变换（包括 xyz，rgb 等）在使用 STNkd 网络生成变换矩阵，变换矩阵[batch_size, 64, 64]，网络结构与 STN 3 d 一致
变换矩阵与数据相乘之后，在使用两层 1 D 卷积塑形成[batch_size, 1024]作为输出的x

同时预留了接口，返回数据
- 只返回全局数据
	- 包括最终的 x 和两个变换矩阵
- 返回局部数据
	- 会把第二个变换矩阵和 x 相乘之后的结果也拼接到 x 中，用于零件分割和语义分割任务
	- 也会返回两个变换矩阵

==最远点云采样==

为了保证采样到的点云足够均匀，采用最远点云采样
首先随机一个起始位置，记录数据索引和坐标，计算所有点到当前点的距离，
更新每一个点与相邻点的最近距离，从中选择距离最大的点作为下一个点
这里最远的的点有两种含义，一个是距离当前点比较远；一个是这个点距离附近点比较远，说明这个点周围密集程度更低

## 分类-cls
分类网络在骨干网络基础上，加上 3 层线性层和 softmax 来分类，线性层除最后一层都使用 Batchnorm 和 relu，第二层还使用了 dropout 层. 返回输出数据和全局特征变换矩阵

**loss**
损失函数包括两部分
- 负对数似然-nll
	- 真实数据和预测数据的分布似然，由于网络中使用了 softmax，这里只是用负对数似然，而不使用 MSE
- 全局变换矩阵的约束
	- 全局变换矩阵与单位矩阵做差，在求和。这里希望约束全局变换矩阵接近正交矩阵，即 $trans*trans^T = E$，

# 部件分割-part_seg
骨干网络和 cls 相似，stn 3 D 网络之后变成了三层卷积来提取特征，三层网络分别保留提取的特征，在经过 stnkl 网络生成的变换矩阵变换，之后经过两层卷积提取特征，池化之后==拼接上物体的标签==，在复制 N 份，和前面五层卷积网络输出的局部特征拼合到一起。在对全部特征进行 4 层卷积，在做 logsoftmax，变成对每一个数据点的部件类别预测
