3 D 数据有很多应用领域，如自动驾驶

## 现有存在问题
点云数据和排列规则的像素网格上的图像不同，3 D 点云是嵌入在连续空间中的集合。这是的 3 D 点云和图像不同，所以不能直接套搬图像中的深度网络设计。

为应对这一挑战，出现了各种针对 3 D 点云的深度学习方法。

体素方法，导致了大量的计算和内存成本，且没有利用 3 D 中点集的稀疏性。稀疏卷积网络通过只在非空像素上操作来缓解体素方法的问题，其他方法直接在点上操作，并通过池化操作或连续卷积传播特征。

另一类方法将点集连接到消息传递的图中

## 论文创新点及可行性讨论
开发了在点云上进行深度学习的方法，源于 transformer 在自然语言处理和图像分析上的成功。

Transformer 特别适合处理点云，因为自注意力算子本质是一个集合算子：他对输入元素的置换和基数是不变的。因此自注意力算子应用于 3 D 点云是自然而然的事，点云本质是嵌入在 3 D 空间中的集合

按照这种直觉进行设计，开发了用于 3 D 点云处理的自注意力层。基于这个层，为各种 3 D 任务构建了 Transformer 网络。我们研究了自注意力算子的形式，==自注意力在每个点的周围的局部邻域的应用==，以及==网络中位置信息的编码==。得到的网络是纯粹基于自注意和逐点计算的.

试验表明，网络非常高效

#  相关工作
对 2 D 图像处理，像素被放到规格网格中，可以用经典卷积进行处理。而3 D 点云在 3 D 空间中是无序和分散的：他们本质是集合。基于学习的方法——处理 3 D 点云可以分为一下几种：基于投影、基于体素、基于点

**基于投影**
处理点云这样的不规则输入，一种直观的方法是把数据转化为规则表述。
考虑到 2 D 卷积网络的成功，一些方法采用多视角投影，把 3 D 点云投影到不同的图像平面上。再使用卷积挽留过对图像平面中提取特征表示，在进行多视角特征融合，最后形成输出表示

总结，这些方法的缺点：
- 严重依赖切线估计（投影平面的选择）
- 点云内部的信息被重叠，内部的点投影的时候被遮住了，识别不到这些点的特征
- 没有利用点云的稀疏性


**基于体素**
将不规则点云转换为规则表示的另一种方法是 3 D 体素化，然后使用 3 D 卷积。

缺点是，3 D 卷积计算量 3 次方增长，会产生大量的计算和内存成本。解决方法是使用稀疏性，因为大多数体素没有被点云占用。这样可以进一步减少计算和内存需求，且已被证明有很好的准确性。但是由于点云量化到体素网格上，仍然可能会丢失一部分集合细节

**基于点**
网络直接提取点云的特征，作为嵌入连续空间的集合。如 pointnet、pointnet++。

将点集连接到一个图中，在图上进行消息传递。如 DGCNN (图卷积神经网络)

许多方法基于连续卷积，直接应用与 3 D 点集，没有量化。

**transformer 和自注意力**
Transformer 和自注意力模型彻底改变了机器翻译和自然语言处理。这激发了 2 D 图像识别的自注意力网络的发展。

受到以下启发：transformers 和自注意力网络可以在序列和 2 D 图像上匹配优于卷积网络。
自注意力在点云中的设置非常有趣，它本质是一个集合算子：位置信息需要提供给网络。由于 3 D 点云本质上是具有位置属性的点的集合，因此自注意力机制好像非常适合这种类型的数据。因此开发了点转换器层，把自注意力应用在 3 D 点云上

之前的论文利用注意力进行点云分心。将全局注意力用在整个点云上，这导致了繁重的计算，并使这些方法不适合大规模 3 D 场景的处理。
他们还是用标量点积注意力，不同的通道共享相同的共享聚合权重，对比之下，我们在局部应用自注意力，这样可以把网络拓展到数百万个点的大型场景，并且我们使用向量自注意力，且我们证明这对实现高精度很重要

还证明了位置编码的重要性，这与之前忽略位置编码的方法形成对比


# 点云transformer

## 背景

自注意力算子分为两种：==标量注意力==和==矢量注意力==

设 $X=\{x_{i}\}$ 是一组特征向量。标准标量*点积*注意力层, 可以表示为：
![image.png|400](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20250811084119808.png)

其中 $\phi,\psi,\alpha$ 对点进行特征变换；$\phi(x_{i})$ 是 quary，$\psi(x_{j})$ 是 key，$\alpha(x_{j})$ 是value，$\delta$ 是位置编码

*矢量注意力*中，注意力权值的计算不同。特别，注意力权重是可以调制单个特征通道的向量：
![image.png|400](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20250811085306043.png)

$\beta$ 是关系函数，比如加法、减法； $\gamma$ 是一个映射函数，用来产生用于特征聚合的注意向量

## 点云 transformer 层
该层是基于向量自注意力的。使用==减法关系==，并在注意力向量 $\gamma$ 和变换后的特征 $\alpha$ 上添加位置编码 $\delta$：
![image.png|500](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20250811091137840.png)

$\phi(x_{i})$ 是查询，$\psi(x_{j})$ 是 key，$x_{j}$ 是在 $x_{i}$ 邻域采样得到的固定数量的点
$\alpha(x_{j})$ 是value

$\gamma$ 映射函数是两个线性层和一个 ReLu 的非线性MLP
$\rho$ 是归一化操作，除以根号维度，在做 softmax

![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20250811091827307.png)

## 位置编码
位置编码在自注意力中有重要作用。序列和图像的标准位置编码方案是手工制作的，例如基于正弦和余弦函数或归一化范围值。3 D 点云处理中，3 D 点坐标本身是位置编码的自然候选者。通过引入可训练、参数化的位置编码来超过传统编码方式。定义 $\delta$ 如下：
![image.png](https://cdn.jsdelivr.net/gh/AustinSuun/image/img/20250811092138463.png)
$p_{i}$ 和 $p_{j}$ 是两个点的坐标。编码函数有两个线性层和一个 ReLU 的非线性 MLP。值得注意的是，法线位置编码对注意力生成分支和转换分支都很重要, 因此两个分支都加上了位置编码。

$p_{i}$ 是初始输入的点，$pj$ 是 $p_{i}$ 为中心的邻域内 knn采样的点


## 点云 transformer 块
以点云 transformer 层为核心的残差 transformer 块。该块继承了自注意力层，可以降低维数和加速处理的线性投影，以及残差连接。

输入是一组 3 D 坐标的特征向量，该块促进了局部特征向量之间的信息交换，为所有数据点产生新的特征向量作为输出。

## 网络架构
基于点云 trnsformer 块构建了完整的 3 d 点云处理网络。
Transformer 是网络的主要聚合特征的算子，不适用卷积进行预处理或者辅助分支；网络完全居于点云 transformer 层、点特征变换和池化


**主干结构**
用来语义分割和分类的点云 transformer 网络的特征编码器有 5 个阶段，这些截断逐步进行下采样。

**下采样-向下过度**
减少点集的基数，如第一阶段到第二阶段数量从 N 降到 N/4
这里直接采用的 pointnet 抽象层，来下采样


**上采样-向上过度**
对语义分割等密集预测任务，需要使用 U-net 设计，使用编码器和对称解码器耦合

将编码器中的连续的层通过上采样层连接起来；其实现，先把层输出的点特征通过另两个 MLP 整合成相同维度，后面借助 pointnet 的上采样模块实现，且不使用 pointnet 上采样模块的 mlp 层

**输出头**
语义分割任务对每一个输入点都产生一个特征向量，代表其类别的独热编码

分类任务，在逐点特征上进行全局平均池化，获得整个点集的全局特征向量，通过 MLP 传递特征获得全局分类

## 消融试验
**邻域采样点的数量**
点云 transformer 层，中使用注意力机制时，需要对每个点采集 k 个邻近点，作为 key 和 value 的输入。

试验了不同的 k 数据，发现 k=16 是表现最好

**softmax 正则化**
对注意力中的归一化函数 $\rho$ 进行了消融研究，和未使用 soffmax 正这话的性能略有下降，表明正则化不可缺少

**位置编码**
没有位置编码的情况下，性能明显下降。使用绝对位置编码，性能比不使用位置编码高。相对位置编码产生最佳性能

只将相对位置编码添加注意力生成分支或值添加到特征变换分支，性能再次下降，表明两个分支中添加相对位置编码是重要的

**注意力类型**
研究了点云 transformer 中使用的自注意力类型，设计了四种条件
MLP 是没有注意力的基线
MLP+池化是更先进的无注意力的基线
标量注意是用标量注意力替换前面使用的矢量注意力
矢量注意力是当前论文使用的

可以看到，标量注意力比无注意力更有表现力，但又被矢量注意力超过
矢量注意力有更强的表现能力，他支持对单个特征通道的自适应调整，而不是整个特征向量，这种表达能力似乎对 3 D 数据处理有益

# 阅读总结
PT 架构最重要的是设计了构成整个架构的点云 Transformer 层、上采样层、下采样层

其中最重要的是点云 Transformer 的设计，上采样层和下采样层和 pointnet++的一致

点云 Transformer 的设计，最重要的是==注意力的计算==，这里设计输入的 xyz 和 points 分别代表前一层的采样点的坐标和点变换后的特征(已经下采样之后)；通过把 xyz 作为查询，xyz 周边的 k 个邻域点作为 key 和 value 的来源，把每个点周边的 k 个邻域点进行MLP 变换，变成 key 和 value；在进行矢量注意力的计算，其中 q 和 k 的关系函数使用减法

对于分类任务，把 transforer 层输出进行平均池化，然后接上 MLP 层分类

对于分割任务，配合上采样层设计了类似 U-net 的结构，然后接上 MLP 对每个点进行分类
